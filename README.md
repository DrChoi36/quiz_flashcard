# 🧠 NEWSTART Quiz (Deep Learning Flashcards)

**NEWSTART Quiz**는 새로운 내용을 공부할 때 복습할 수 있도록 돕는 웹 기반 플래시카드 퀴즈 애플리케이션입니다.

직관적인 카드 뒤집기 인터페이스를 통해 용어, 개념, 작동 원리 등을 효과적으로 암기할 수 있습니다.

## ✨ 주요 기능 (Key Features)

* **인터랙티브 플래시카드**: 카드를 클릭하거나 터치하여 앞면(질문)과 뒷면(정답 및 설명)을 오갈 수 있습니다.
* **학습 진행 상황 표시**: 전체 30문제 중 현재 몇 번째 카드를 학습 중인지 상단에 표시됩니다.
* **반응형 디자인 (Responsive Design)**: PC와 모바일 환경 모두에서 최적화된 레이아웃을 제공합니다.
* **키보드 단축키 지원**: 마우스 없이 키보드만으로 편리하게 조작할 수 있습니다.
* **학습 완료 피드백**: 모든 카드를 학습하면 완료 메시지가 표시되며, 다시 시작할 수 있습니다.

## 🛠 기술 스택 (Tech Stack)

* **HTML5**: 시맨틱 마크업 구조
* **CSS3**: Flexbox 레이아웃, 3D Transform(카드 뒤집기 효과), 애니메이션
* **JavaScript (Vanilla)**: 외부 라이브러리 없이 순수 자바스크립트로 로직 구현

## 🚀 사용 방법 (How to Use)

### 실행 방법
별도의 설치가 필요 없으며, `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 열기만 하면 바로 실행됩니다.

### 조작 가이드

| 동작 | 마우스 / 터치 | 키보드 단축키 |
| :--- | :--- | :--- |
| **카드 뒤집기** | 카드 영역 클릭 | `Space` |
| **다음 문제** | 오른쪽 화살표 버튼 (❯) | `Right Arrow (→)` 또는 `Enter` |
| **이전 문제** | 왼쪽 화살표 버튼 (❮) | `Left Arrow (←)` |
